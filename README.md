# Revista **Spooler** (Portugal)

> Uma homenagem à *Spooler*, uma revista que ajudou a formar geeks — e que, para quem começou a programar no final da década de 80 (1989), foi essencial para ler e **vasculhar o código** que vinha nas disquetes.

## O que foi a Spooler
A **Spooler** foi uma revista portuguesa de informática, com forte componente prática: ensino através de exemplos, partilha de código, programação, utilitários e cultura “hands-on”.
Uma das suas marcas mais lembradas é o facto de **acompanhar disquetes** com software e ficheiros relacionados com os conteúdos da revista — incluindo material enviado por leitores.

Este repositório existe para **preservar memória**, **organizar referências** e **facilitar a descoberta** do acervo digital disponível online.

## Porque este repositório existe (nota pessoal)
Comecei a programar no final dos anos 80 / início dos anos 90 e **tive assinatura** da Spooler.  
Este repositório é a minha forma de:
- catalogar edições, temas e conteúdos associados (incluindo disquetes);
- partilhar um pedaço dessa história com quem viveu (ou quer conhecer) essa época.

## Estrutura do repositório (GitHub)
Repositório: https://github.com/vnmcosta/SpoolerMagazine/tree/main

A organização segue uma lógica simples **por número/edição**:
- `README.md` — esta página (contexto, links e organização).
- `Spooler-37/` — materiais referentes à edição nº 37.
- `Spooler-38/` — materiais referentes à edição nº 38.
- `Spooler-39/` — materiais referentes à edição nº 39.

> À medida que forem sendo adicionadas novas edições, a ideia é manter o padrão `Spooler-<número>/` para facilitar a navegação e pesquisa.

## O que encontravas na revista
Alguns exemplos do tipo de conteúdos associados à Spooler:
- listas de programas/jogos (incluindo envios de leitores e shareware) na disquete;
- rotinas e código (ex.: rotinas para Pascal, código-fonte incluído em utilitários);
- temas “clássicos” do PC: BBS, compressão de dados, ordenação/localização, memória, impressoras;
- artigos de iniciação/continuação (ex.: programação orientada por objetos).
